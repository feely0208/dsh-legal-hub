# 深鲸法律台（DSH 插件）

**DSH 侧栏里的法律工具集中入口。** 一个面板看全 4 个法律工具，点卡片直接跳到对应面板；没装的给出明确提示。

## 为什么需要它

DSH 的 `sidebar.panellist` 只支持 `{ id, order, label }`，**没有分组/折叠能力**。法律工具是 4 个独立插件，散在侧栏里不好找。这个插件就是那个「大项」：

- 侧栏固定一个「深鲸法律台」入口；
- 面板里列出合同体检、引用核验、合规文书、中文排版；
- 点「打开」调用 `ctx.layout.selectPanel(id)` 跳到对应面板；
- 另附技能库、脱敏 App、法律专区三个官网入口。

## 安装

```bash
dsh plugin --profile web add @deepwhale-cn/dsh-legal-hub
```

或插件市场搜索「深鲸法律台」。重启 DSH 后侧栏出现图标。

## 说明

- 纯客户端插件，无后端、不联网、不上传；
- 跳转依赖宿主 `ctx.layout.selectPanel`，不可用时给出安装提示，不假装成功；
- 输出均为草稿，须由承办律师复核。
